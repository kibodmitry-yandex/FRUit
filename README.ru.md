# FRUit — Folder Restore Utility

**F**older **R**estore **U**tility (for **E**xplorer navigation) — утилита для
Windows 11, которая сохраняет окна и вкладки Проводника и возвращает их.

Надоело после каждой перезагрузки (или — что хуже — после аварийного
перезапуска `explorer.exe`) заново открывать десяток папок? Системное
восстановление работает нестабильно, а после краха — вообще не всегда. FRUit
запоминает раскладку и возвращает её: по одной группе, по одному окну или всё
сразу.

## Возможности

- **Снимок окон и вкладок** через `IShellWindows`: каждая вкладка хранится по
  своему уникальному адресу.
- **Геометрия и состояние окна** (позиция, размер, развёрнуто/обычно) —
  `GetWindowPlacement` / `SetWindowPos`.
- **Значок в трее** (папка с бананом): группы вкладок (🗂, по первой вкладке)
  и отдельные окна (🗀); у каждой записи подменю — состав (серый, только для
  чтения), «Восстановить», «✕ Удалить», плюс «Восстановить все».
- **Без дублей:** одинаковый набор вкладок не сохраняется дважды, а если
  раскладка уже открыта — окно просто выходит на передний план, а не
  открывается заново.
- **Горячие клавиши:** `Ctrl+Alt+S` — снапшот, `Ctrl+Alt+R` — восстановить все.
- **Тихий трей:** без окна консоли, ошибки — в `logs\fruit.log`
  (ротация при 1 МБ).
- **Тонкий `FRUit.exe`** — запускает текущий Python-код своим окружением,
  пересобирать после правок не нужно.
- **Именованные снапшоты в CLI** — профили раскладок (работа/дом).

## Установка

Нужны Windows 11 и доступ в интернет (для Python и pip).

**Простейший способ:**

1. Скачайте репозиторий ZIP-архивом (*Code → Download ZIP*) или клонируйте:
   `git clone https://github.com/kibodmitry-yandex/FRUit.git`
2. Запустите **`install.bat`** двойным кликом: он найдёт Python 3.9+
   (тихо поставит через winget, если его нет), создаст `.venv` и установит
   зависимости.
3. Запустите **`FRUit.exe`** — появится значок в трее.

Вручную:

```bat
py -3 -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
```

`FRUit.exe` использует `.venv` этого репозитория, поэтому держите папку на
месте.

## Использование

### Трей (основной режим)

Двойной клик по `FRUit.exe` — в системном трее появится значок «папка с
бананом» (окно консоли не открывается). Правый клик → меню:

```
Сделать снапшот                    ← запомнить текущие группы/окна (без дублей)
Восстановить все                   — открыть всё из списка
────────────────────────────────────
🗂 Projects (5 вкл)   ┐ состав группы (серые пункты только для чтения):
        • src • docs   │ видно, что именно откроет «Восстановить»;
        • tests • media┘ у одиночного окна — полный путь
        ────────────────────────
        Восстановить
        ✕ Удалить🗀 Downloads
        • C:\Users\me\Downloads
        ────────────────────────
        Восстановить
        ✕ Удалить
────────────────────────────────────
Папка данных
Выход
```

Клик по строке раскладки открывает подменю: Win32-меню не делит строку на две
кликабельные зоны, поэтому «Восстановить» живёт внутри подменю. Уже открытая
раскладка не дублируется — окно выводится на передний план, геометрия и
активная вкладка не меняются.

Глобальные горячие клавиши: `Ctrl+Alt+S` — снапшот, `Ctrl+Alt+R` —
восстановить все. Посмотреть меню текстом, не открывая трей:

```bat
.venv\Scripts\python.exe tools\dump_menu.py
```

### Командная строка (именованные снапшоты)

```bat
FRUit.exe save work                      :: сохранить текущую раскладку как work
FRUit.exe list                           :: список снапшотов
FRUit.exe restore work                   :: восстановить (вкладки собираются в окна)
FRUit.exe restore work --no-tabs         :: надёжнее: каждая папка отдельным окном
FRUit.exe restore latest                 :: восстановить самый свежий снапшот
FRUit.exe delete work                    :: удалить снапшот
```

### Где хранятся данные

По умолчанию в `%LOCALAPPDATA%\FRUit`: `snapshots\*.json` (именованные
снапшоты) и `groups.json` (список трея). Каталог переопределяется переменной
`FRUIT_DATA`.

`FRUIT_HOME` — это другое: каталог с **пакетом** `fruit` (нужен exe-лаунчеру,
если он лежит не в корне репозитория).

## Как это работает

- Перечисление окон и вкладок — `IShellWindows` (вкладки группируются по
  дескриптору окна).
- Первая вкладка открывается через `explorer.exe`; остальные добавляются
  Invoke кнопки *Add New Tab* (UI Automation) и навигируются адресно через
  `IWebBrowser2.Navigate`.
- Если вкладку добавить не удалось — папка открывается **отдельным окном**
  (откат), чтобы ни одна папка не потерялась.
- Геометрия окна — `GetWindowPlacement` / `SetWindowPos`.

В Windows 11 вкладки Проводника реализованы внутри XAML/WinUI и **не
экспонированы для сторонней автоматизации** — официального API их создания нет
(см. [Microsoft Learn](https://learn.microsoft.com/en-us/answers/questions/5852400/)).

## Ограничения

- **Восстановление вкладок — через UI Automation.** При недоступности кнопки
  или навигации папка открывается отдельным окном: раскладка максимально
  близко, но папки **не теряются**.
- **Нет иконок у пунктов меню** (Win32/pystray) — «группа/окно» различаются
  глифами 🗂 / 🗀.
- **Строка меню — одна зона клика:** клик по записи открывает подменю, поэтому
  «Восстановить» живёт в подменю, а не в самой строке.
- **Виртуальные папки** («Этот компьютер», «Быстрый доступ», «Корзина») не
  имеют файлового адреса — пропускаются с предупреждением; обрабатываются
  только окна класса `CabinetWClass`.
- **Амперсанд `&` в именах папок** удваивается в тексте меню (правило
  ускоряющих клавиш Win32).

## Разработка

- `launcher\` — исходник тонкого exe (`FruitLauncher.cs`), `build_launcher.bat`
  (сборка системным `csc.exe`) и генератор иконки `make_icon.py`.
- `tools\` — скрипты отладки и тесты, в поставку не входят.
- Иконка: `launcher\logo.png` → `python launcher\make_icon.py` пересобирает
  `fruit.ico` / `fruit.png` (кадры 16…256 px). Без png значок рисуется кодом
  Pillow — ничего не ломается.
